# 纯前端刷题软件设计与实现计划

## 一、项目架构

### 1. 技术栈
- **核心框架**: React 18 + TypeScript + Vite
- **数据存储**: IndexedDB (支持大量数据，适合本地使用)
- **文件处理**: 
  - mammoth.js (Word .docx解析)
  - xlsx (Excel .xlsx解析)
  - pdf-parse (PDF .pdf解析)
- **状态管理**: React Context + useReducer
- **样式**: Tailwind CSS
- **UI组件**: 自定义组件 + 少量第三方组件

### 2. 项目结构
```
reviewApp/
├── src/
│   ├── components/          # React组件
│   │   ├── Question/        # 题目相关组件
│   │   ├── ExamMode/        # 考试模式组件
│   │   ├── ReviewMode/      # 背题模式组件
│   │   ├── Import/          # 导入功能组件
│   │   └── Layout/          # 布局组件
│   ├── hooks/              # 自定义钩子
│   ├── services/           # 业务逻辑服务
│   │   ├── db/             # IndexedDB封装
│   │   ├── fileParser/     # 文件解析服务
│   │   └── exam/           # 考试相关服务
│   ├── store/              # 状态管理

└── package.json            # 项目配置
```

## 二、核心功能实现

### 1. 题库管理

#### 导入功能
- **支持格式**: Word (.docx)、Excel (.xlsx)、PDF (.pdf)
- **智能解析**: 
  - 支持多种常见题目格式模板
  - 自动识别题目类型、选项、答案
  - 提供导入预览和错误提示
  - 支持手动调整解析结果

#### 题目类型
- **单选题**: 一个正确选项，自动批改
- **多选题**: 多个正确选项，自动批改
- **简答题**: 主观作答，支持参考答案对比

### 2. 刷题模式

#### 考试模式
- 模拟真实考试环境
- 自定义考试时长
- 随机/顺序抽取题目
- 自动计时和交卷
- 客观题自动批改
- 考试结果分析（正确率、用时等）

#### 背题模式
- 查看题目及答案解析
- 标记重点/难点题目
- 错题集自动生成
- 按分类/难度筛选题目
- 进度追踪

### 3. 数据管理
- **本地存储**: 使用IndexedDB存储题库、考试记录和用户偏好
- **数据导出**: 支持将题库导出为JSON格式
- **数据备份**: 提供手动备份和恢复功能

## 三、核心技术实现

### 1. 文件解析策略

#### Word解析 (mammoth.js)
- 提取文档结构和样式
- 识别题目编号、选项标记
- 支持多种题目模板

#### Excel解析 (xlsx)
- 读取工作表数据
- 支持表头映射
- 批量导入题目

#### PDF解析 (pdf-parse)
- 提取文本内容
- 识别题目结构
- 支持常见PDF格式

### 2. 状态管理设计

#### 全局状态
- 题目数据: 题库、当前题目
- 用户设置: 主题、字体大小、默认时长
- 考试状态: 当前考试、答题记录

#### 本地存储
- 使用IndexedDB存储大量题目数据
- localStorage存储用户偏好设置

### 3. 界面设计
- **响应式布局**: 支持桌面端和移动端
- **简洁现代UI**: Tailwind CSS实现
- **主题切换**: 浅色/深色模式
- **流畅动画**: 提升用户体验
