# 方案1：科目/题库隔离功能实施计划

## 核心思路
利用现有 `category` 字段作为科目标识，实现多科目题库共存，支持科目管理、按科目导入和筛选。

## 实施步骤

### 1. 增强题库管理页面（QuestionBank.tsx）
- 优化科目筛选下拉框，支持创建新科目
- 添加科目管理功能（删除、重命名科目）
- 增加按科目统计题目数量
- 添加批量操作功能（按科目导出/删除）

### 2. 修改导入页面（Import.tsx）
- 添加科目选择下拉框
- 支持导入时创建新科目
- 显示当前选择科目的题目数量
- 优化导入结果提示

### 3. 更新考试模式（ExamMode.tsx）
- 在考试设置中添加科目选择
- 支持按科目随机抽取题目
- 考试结果中显示科目信息

### 4. 更新背题模式（ReviewMode.tsx）
- 在背题设置中添加科目选择
- 支持按科目筛选要背的题目
- 背题进度按科目保存

### 5. 优化统计分析（Statistics.tsx）
- 支持按科目查看统计数据
- 增加科目对比功能
- 优化图表展示

## 技术实现

### 数据库层面
- 无需修改现有结构，利用 `category` 字段作为科目标识
- 现有题目自动归类到默认科目

### 代码修改
1. **QuestionBank.tsx**: 添加科目管理功能
2. **Import.tsx**: 添加科目选择
3. **ExamMode.tsx**: 添加科目筛选
4. **ReviewMode.tsx**: 添加科目筛选
5. **Statistics.tsx**: 增强统计功能

## 预期效果

1. **多科目共存**: 支持同时管理多个科目题库
2. **灵活切换**: 方便在不同科目间切换
3. **高效导入**: 导入时可直接选择或创建科目
4. **精准筛选**: 各功能模块均可按科目筛选
5. **完整统计**: 支持按科目查看统计数据

## 实施优先级

1. 题库管理页面增强
2. 导入页面修改
3. 考试模式更新
4. 背题模式更新
5. 统计分析优化

这个方案将提供良好的用户体验，支持长期使用需求，并具有良好的扩展性。
